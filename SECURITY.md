# Security reporting

This is a pre-public-release review package. A monitored public vulnerability
reporting address has not yet been established. Contact the maintainer through
the channel that supplied your copy. Do not post credentials, confidential client
drawings or exploit details publicly. This reporting workflow does not restrict
the software license.

Include version, operating system, affected feature and a minimal reproduction
using non-confidential sample data. Review logs before sharing them: they may
contain paths or drawing details. Send no employer/client material without
authorization. Another supplier's site is not this independent project's channel.

No supported-version timetable, response-time SLA or security certification is
declared. Public launch must provide a monitored contact and realistic support
policy. Applicable statutory reporting duties need assessment for the actual
activity and markets. See legal/RELEASE_READINESS.md.
