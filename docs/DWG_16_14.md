# DWG opening — PY.cad 16.14

Use Ctrl+O or the top-left logo → Open and select a .dwg file. Import → DWG and
recent files use the same opening path. No ODA installation is needed on the
bundled-reader platforms. The reader runs locally; no drawing is uploaded.

Windows x64 includes official GNU LibreDWG 0.14 dwg2dxf plus its DLL. Linux x64
includes a reader built from upstream source, requiring glibc 2.38+ (Ubuntu
24.04 and 26.04 are compatible). The rest of the application retains its prior
Linux requirements; older Linux systems need a locally built compatible reader
for DWG. A macOS reader is not bundled: install GNU LibreDWG dwg2dxf and put it on
PATH, or set PYCAD_DWG_CONVERTER to the absolute path of the executable. The same
override supports a separately built reader on another platform. Help → DWG
support shows the selected reader or a clear missing/compatibility message.

Opening copies the source into a private temporary conversion directory, runs
LibreDWG as a directly cancellable process, then reads the resulting DXF in the
existing separate import worker. It preserves the source's DXF version rather
than forcing an upgrade. Cancel and failures leave the current workspace intact.
Conversion has a two-minute deadline; total opening has a five-minute deadline.
Input and converted DXF are limited to 100 MiB, with the existing native/entity
limits also retained. Temporary files are removed after completion/cancellation.

The source DWG is never overwritten. Its name/path and, within the existing
16 MiB source-archive limit, its original bytes are retained in a saved .pycad
project. Save your editable work to a new .pycad file. Every DWG import carries
an import notice, and existing unsupported-entity notices are retained. Some
proxy objects, Xrefs, advanced DWG entities, fonts, 3D data and application-specific
metadata may be missing or approximated. This is editable import of supported
geometry, not lossless AutoCAD parity. Review dimensions, units and content.

This change adds opening/import, not native DWG saving. Optional existing DWG
export still needs a separately installed ODA converter under its own terms.
DXF and .pycad saving remain available without ODA.

The bundled binaries are checked against their SHA-256 manifest before use.
The unmodified LibreDWG corresponding source archive, licenses, notices,
provenance and rebuild instructions are included in vendor/libredwg. The project
remains open source; upstream code keeps its own copyrights and license.

Validation: real upstream Line.dwg fixtures from 2000, 2004, 2007, 2010, 2013 and
2018 DWG formats opened using the Linux reader without ODA. Tests checked source
hashes, original-byte archives, .pycad save/reopen and overwrite prevention; a
real GUI-process import kept event handling alive. Cancellation and timeout
checks terminated the direct converter and preserved the active workspace.
These fixtures establish basic-format acceptance, not every entity in every
DWG. Windows reader PE imports/structure and all setup targets are checked;
actual Windows conversion/install/uninstall and macOS execution are not tested
in this Linux environment. No user-provided problem DWG was available for testing.
