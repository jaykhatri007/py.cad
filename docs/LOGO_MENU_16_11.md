# PY.cad 16.11

The approved symbol is the single application-menu button in Quick Access. Click it or press Alt+F to open the existing File workspace. The separate File labels and duplicate logo wordmark have been removed. New/Open/Save/Save As/Print shortcuts are retained. The logo remains accessible when the traditional menu bar is hidden.

Graphics: the retained renderer supports Auto, Hardware (OpenGL) and Software modes, diagnostics and fallback. Available acceleration depends on the GPU and driver. Geometry, DXF parsing and quantities calculations still run on the CPU. No physical GPU performance or native Windows GUI acceptance is claimed by this release.

The native Windows setup frame from 16.10 is retained.
